# The Galle Face Hotel — Colombo landmark model

1864 Victorian colonial seaside grand hotel on Galle Face with North and South ocean wings, multi-tier verandah loggias, terracotta hipped roofs with gables and dormers, and seafront pool.

## Included files
- galle-face-hotel.blend: editable Blender 5.2 source, organized architectural collections, PBR materials, preview camera and lighting.
- galle-face-hotel.glb: standalone detailed model; metres, glTF Y up; no external textures needed.
- map.glb: lighter export without the smallest decorative trims.
- preview.png / preview.jpg: rendered preview, transparent background.
- detail.png: architectural detail close-up.

## Fidelity
Exterior visual reconstruction from public photographs, mapped footprint context and published building descriptions. Heights, plans, colours and ornament are approximate.
Detailed mesh: 49,884 triangles. Map mesh: 45,756 triangles.
Dimensions (X / Y / Z in Blender metres): 116.0 / 72.0 / 23.0.

Reference: 2 Galle Road, Kollupitiya, Colombo 03
Map origin / placement (Three.js X east, Y up, Z south): [-1354, 0, 753]; local Blender Z rotation: 0 rad.
Built from scripts/build_expansion_blender.py.
