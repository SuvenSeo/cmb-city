# Fort Light & Clock Tower — Colombo landmark model

1857 Victorian ashlar lighthouse and clock tower at Chatham Street crossroads with four-way arched rusticated base, quoined shaft, Roman clock faces, and brass lantern dome.

## Included files
- clock-tower.blend: editable Blender 5.2 source, organized architectural collections, PBR materials, preview camera and lighting.
- clock-tower.glb: standalone detailed model; metres, glTF Y up; no external textures needed.
- map.glb: lighter export without the smallest decorative trims.
- preview.png / preview.jpg: rendered preview, transparent background.
- detail.png: architectural detail close-up.

## Fidelity
Exterior visual reconstruction from public photographs, mapped footprint context and published building descriptions. Heights, plans, colours and ornament are approximate.
Detailed mesh: 14,740 triangles. Map mesh: 14,740 triangles.
Dimensions (X / Y / Z in Blender metres): 14.5 / 11.0 / 29.0.

Reference: Chatham Street & Janadhipathi Mawatha, Fort, Colombo 01
Map origin / placement (Three.js X east, Y up, Z south): [-1480, 0, -880]; local Blender Z rotation: 0 rad.
Built from scripts/build_expansion_blender.py.
