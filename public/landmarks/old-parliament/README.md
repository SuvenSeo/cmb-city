# Old Parliament Building — Colombo landmark model

1930 Neo-Baroque buff sandstone palace facing Galle Face Green with grand monumental staircase, hexastyle Ionic portico, and central dome.

## Included files
- old-parliament.blend: editable Blender 5.2 source, organized architectural collections, PBR materials, preview camera and lighting.
- old-parliament.glb: standalone detailed model; metres, glTF Y up; no external textures needed.
- map.glb: lighter export without the smallest decorative trims.
- preview.png / preview.jpg: rendered preview, transparent background.
- detail.png: architectural detail close-up.

## Fidelity
Exterior visual reconstruction from public photographs, mapped footprint context and published building descriptions. Heights, plans, colours and ornament are approximate.
Detailed mesh: 48,900 triangles. Map mesh: 39,156 triangles.
Dimensions (X / Y / Z in Blender metres): 134.0 / 55.7 / 38.84.

Reference: Galle Face North, Fort, Colombo 01
Map origin / placement (Three.js X east, Y up, Z south): [-1580, 0, -180]; local Blender Z rotation: 0 rad.
Built from scripts/build_expansion_blender.py.
