# One Galle Face & Shangri-La Colombo — Colombo landmark model

Twin 50-storey glass towers (194m) and Shangri-La Hotel commanding the Galle Face oceanfront with curved retail mall podium, infinity pools, and high-performance reflective curtain walls.

## Included files
- one_galle_face.blend: editable Blender 5.2 source, organized architectural collections, PBR materials, preview camera and lighting.
- one_galle_face.glb: standalone detailed model; metres, glTF Y up; no external textures needed.
- map.glb: lighter export without the smallest decorative trims.
- preview.png / preview.jpg: rendered preview, transparent background.
- detail.png: architectural detail close-up.

## Fidelity
Exterior visual reconstruction from public photographs, mapped footprint context and published building descriptions. Heights, plans, colours and ornament are approximate.
Detailed mesh: 7,288 triangles. Map mesh: 7,288 triangles.
Dimensions (X / Y / Z in Blender metres): 148.0 / 97.0 / 194.6.

Reference: 1A Centre Road, Galle Face, Colombo 02
Map origin / placement (Three.js X east, Y up, Z south): [-1450, 0, 20]; local Blender Z rotation: 0 rad.
Built from scripts/build_expansion_blender.py.
