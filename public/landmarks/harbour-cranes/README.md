# Colombo Harbour & Container Terminals — Colombo landmark model

Colombo Port deepwater container quay with towering 75m Ship-to-Shore (STS) gantry cranes, rail tracks, colorful intermodal container stacks, and moored container cargo vessel.

## Included files
- harbour-cranes.blend: editable Blender 5.2 source, organized architectural collections, PBR materials, preview camera and lighting.
- harbour-cranes.glb: standalone detailed model; metres, glTF Y up; no external textures needed.
- map.glb: lighter export without the smallest decorative trims.
- preview.png / preview.jpg: rendered preview, transparent background.
- detail.png: architectural detail close-up.

## Fidelity
Exterior visual reconstruction from public photographs, mapped footprint context and published building descriptions. Heights, plans, colours and ornament are approximate.
Detailed mesh: 6,824 triangles. Map mesh: 6,824 triangles.
Dimensions (X / Y / Z in Blender metres): 240.0 / 119.06 / 72.08.

Reference: Colombo Harbour & Jaya Container Terminal, Colombo 01
Map origin / placement (Three.js X east, Y up, Z south): [-1450, 0, -1850]; local Blender Z rotation: 0 rad.
Built from scripts/build_expansion_blender.py.
