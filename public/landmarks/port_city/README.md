# Colombo Port City & Marina — Colombo landmark model

Reclaimed maritime peninsula with Port City Marina yacht club, iconic sweeping tensile fabric sail canopy, deep-water pontoon berths with luxury yachts, ocean seawall promenade, and lighthouse beacon.

## Included files
- port_city.blend: editable Blender 5.2 source, organized architectural collections, PBR materials, preview camera and lighting.
- port_city.glb: standalone detailed model; metres, glTF Y up; no external textures needed.
- map.glb: lighter export without the smallest decorative trims.
- preview.png / preview.jpg: rendered preview, transparent background.
- detail.png: architectural detail close-up.

## Fidelity
Exterior visual reconstruction from public photographs, mapped footprint context and published building descriptions. Heights, plans, colours and ornament are approximate.
Detailed mesh: 11,464 triangles. Map mesh: 11,464 triangles.
Dimensions (X / Y / Z in Blender metres): 196.0 / 130.77 / 32.2.

Reference: Port City Boulevard, Port City, Colombo 01
Map origin / placement (Three.js X east, Y up, Z south): [-1950, 0, -350]; local Blender Z rotation: 0 rad.
Built from scripts/build_expansion_blender.py.
