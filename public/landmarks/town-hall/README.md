# Colombo Town Hall — Colombo landmark model

Neoclassical civic palace overlooking Viharamahadevi Park with colossal Corinthian hexastyle portico, pediment, rusticated arcades, and high ribbed dome.

## Included files
- town-hall.blend: editable Blender 5.2 source, organized architectural collections, PBR materials, preview camera and lighting.
- town-hall.glb: standalone detailed model; metres, glTF Y up; no external textures needed.
- map.glb: lighter export without the smallest decorative trims.
- preview.png / preview.jpg: rendered preview, transparent background.
- detail.png: architectural detail close-up.

## Fidelity
Exterior visual reconstruction from public photographs, mapped footprint context and published building descriptions. Heights, plans, colours and ornament are approximate.
Detailed mesh: 58,754 triangles. Map mesh: 47,714 triangles.
Dimensions (X / Y / Z in Blender metres): 102.0 / 74.59 / 39.6.

Reference: F. R. Senanayake Mawatha, Cinnamon Gardens, Colombo 07
Map origin / placement (Three.js X east, Y up, Z south): [120, 0, 1220]; local Blender Z rotation: 0 rad.
Built from scripts/build_expansion_blender.py.
