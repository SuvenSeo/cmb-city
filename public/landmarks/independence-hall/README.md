# Independence Memorial Hall — Colombo landmark model

Kandyan Royal Audience Hall national monument featuring 60 carved stone pillars with Pekada floral bracket capitals, four-tiered plinth, guardian lions, and double Kandyan terracotta roof.

## Included files
- independence-hall.blend: editable Blender 5.2 source, organized architectural collections, PBR materials, preview camera and lighting.
- independence-hall.glb: standalone detailed model; metres, glTF Y up; no external textures needed.
- map.glb: lighter export without the smallest decorative trims.
- preview.png / preview.jpg: rendered preview, transparent background.
- detail.png: architectural detail close-up.

## Fidelity
Exterior visual reconstruction from public photographs, mapped footprint context and published building descriptions. Heights, plans, colours and ornament are approximate.
Detailed mesh: 25,728 triangles. Map mesh: 25,728 triangles.
Dimensions (X / Y / Z in Blender metres): 77.5 / 59.35 / 21.2.

Reference: Independence Square, Cinnamon Gardens, Colombo 07
Map origin / placement (Three.js X east, Y up, Z south): [240, 0, 2580]; local Blender Z rotation: 0 rad.
Built from scripts/build_expansion_blender.py.
